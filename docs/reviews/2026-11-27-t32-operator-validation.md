# T32 归一化算子优化与全长整链验收

2026-11-27。基线 main 765782d，RK3588、三核 NPU、A76 CPU 1–4、Runtime 2.5.0、驱动 0.9.8。按安排等待另一项板测完成后独占测试。

## 采用的版本

默认保留保真档（history=48ms、overlap=48ms、stride=152ms）。新模型保持 NVIDIA 原权重和单步条件，关闭高斯采样、dry=0，只改归一化算子的统计与仿射计算。六段实录上音质预测分与旧模型几乎一致，NPU 块均值从116.08降至104.12ms，约快10.3%。

平衡档使用同一模型，history=64ms、overlap=48ms、stride=136ms。估计内容延迟 P95 约399–400ms，音质分略低；最大约411ms，仍未保证严格400ms，也未测声卡和网络。AGC③旁路是独立可选项，六段预测分均有小幅提升，保留默认AGC以便调用方按电平需求选择。

## 数值与算子验证

归一化使用 E[x²]−E[x]²（负舍入误差夹到0），并先计算通道大小的仿射项再广播。FP32五组检查的最大相对RMS差为3.10e−6；浮点重排在FP16中仍会产生舍入差异。

实际板端54个相同输入张量（含预热、实录、静音、音调、1LSB信号）对原生FP32：旧版相对RMS 0.4709%，新版0.4750%，相关分别0.99999043/0.99999038，均为有限数。同几何8秒PCM新旧相关0.99999699，相对RMS差0.2459%。验证范围有限，运行器增加非有限输出检查。

非profiling的8秒测试NPU均值114.812→103.377ms；全长重测均值见下表。逐算子profiling显示归一化约占原图时间49.7%，但profiling有额外开销，未将其总耗时当实时性能。Toolkit2为2.3.2。

## 已排除的方案

- 旁路DPDF：meeting_1/3估计延迟约362ms，但OVRL约下降0.43/0.49，背景残留加重，未采用。
- history=80ms或对称64ms交叠：在已测两段里收益不足或音质变差，未推广到默认。
- 只合并仿射项：约节省2.8ms，低于采用的二阶矩方案。
- 另一项已完成整链实验的反序、v4结果见[顺序报告](2026-11-27-meeting-chain-results.md)，本轮保留DPDF→NVIDIA；未把不同输入量化方式的旧结果混入当前排名。

## 数据与复现

原始10项SHA全部复核通过。六段10通道中0–7为麦克风，8/9参考接近静音，因此无法验收有效回声或双讲。meeting_3/4只在派生副本上将麦克风联合RMS调整到−36dBFS，分别+32.863352/+36.785251dB；PCM16转换向下取整，与本次验收输入SHA一致。参考通道不变。加增益无法恢复录音时已丢失的量化精度。

```sh
python scripts/eval/prepare_meeting_inputs.py data/raw /absolute/derived-inputs
python scripts/board/build_audio3a.py /absolute/bundle --cc /path/to/aarch64-linux-gnu-gcc --ort-include /path/to/include --ort-lib /path/to/lib
# NVIDIA运行器构建依赖及模型复制见 scripts/board/LIVE.md 与 src/audio3a/README.md
sh scripts/board/replay_audio3a.sh /absolute/bundle /absolute/derived-inputs/meeting_1.raw10ch.wav /absolute/results/quality.wav --pace --bypass-post-nvidia-agc
AUDIO3A_NVIDIA_PROFILE=balanced sh scripts/board/replay_audio3a.sh /absolute/bundle /absolute/derived-inputs/meeting_1.raw10ch.wav /absolute/results/balanced.wav --pace --bypass-post-nvidia-agc
```

本轮DPDF使用原始FP32 dpdfnet2.onnx（ce35d602…487a9），与CPU改写图以SHA区分。其他CPU图改写可通过AUDIO3A_DPDF_MODEL显式选择，需分别验收。库固定ONNX Runtime1.24.4与RKNN Runtime2.5.0；二进制和库SHA在运行包清单。

DNSMOS统一去直流、整体RMS0.03、限幅、9.01秒窗/1秒步进；两线程评分。包含完整录音窗口，开头/停顿也计入，不能直接对比2秒步进的其他报告。没有干净真值，SIG/BAK/OVRL不能替代逐字可懂度或真人保真判断。试听仅作固定增益同响度和约92ms波形对齐，末尾对齐填零不用于新增评分。

正式生产二进制再以两档各两次12秒paced回放检查，全部零NVIDIA块超预算；非有限检查不改变验证集PCM；实际T32配成T16时运行器及父进程返回失败。输入派生脚本逐字节重现六段输入。主机回归验证前级一致、处理顺序、AGC旁路/恢复、长度、缺模型和非法几何。
